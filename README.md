
# 🤖 Jarvis Voice Assistant
Voice assistant in Python

A Python voice assistant that can:
- Play music from YouTube
- Open websites (Google, Gmail, YouTube, Facebook, etc.)
- Answer questions via Google search fallback
- Listen and respond to voice commands
- Open News

## 🔧 Technologies Used
- Python
- SpeechRecognition
- PyAudio
- pyttsx3

## 🚀 Features
- Wake word: "Jarvis"
- Google search fallback
- Voice output

## Required Libraries need to install
pip install speechrecognition pyttsx3 pipwin
pipwin install pyaudio

## Run as
python main.py
