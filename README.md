# 🤖 Jarvis Voice Assistant
A Python voice assistant that can:
- Play music from YouTube
- Open websites (Google, Gmail, YouTube, Facebook, etc.)
- Answer questions via Google search fallback
- Listen and respond to voice commands
- Open News

## 🔧 Technologies Used
- Python
- SpeechRecognition
- PyAudio
- pyttsx3

## 🚀 Features
- Wake word: "Jarvis"
- Google search fallback
- Voice output
